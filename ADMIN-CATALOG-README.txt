CAMEO ADMIN CATALOG UPDATE

1. Upload this complete folder to GitHub/hosting.
2. Keep your existing supabase-config.js project URL and publishable key.
3. Open admin.html and sign in as the owner.
4. The admin automatically checks Supabase and adds any missing original Cameo catalog products.
5. Products you already uploaded are NOT deleted or overwritten.
6. After sync, all categories can be filtered and every database product can be edited/deleted.
