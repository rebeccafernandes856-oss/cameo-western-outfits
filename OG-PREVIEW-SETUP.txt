WhatsApp Open Graph previews for GitHub Pages

GitHub Actions generates product OG preview pages from catalog-seed.js during deployment. Set repository variable SITE_URL to your full public website URL (for example https://example.com), with no trailing slash. If not set, the workflow uses CNAME or the GitHub Pages repository URL.

For each catalog seed product, share /products/item-001.html etc to get an image preview. WhatsApp usually shows only one preview per message and OG tags DO NOT attach image files. Admin-added Supabase products are NOT automatically generated by this static build; export/update the catalog seed and redeploy for those products.

Images must be publicly reachable and WhatsApp may cache previews.
