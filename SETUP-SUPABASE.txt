CAMEO WESTERN OUTFITS — SUPABASE SETUP
======================================

1. Create a Supabase project.
2. Open SQL Editor and run the complete file: supabase-schema.sql
3. Open Project Settings / API and copy:
   - Project URL
   - Publishable key (or legacy anon key)
4. Open supabase-config.js and paste those two values.
   IMPORTANT: Never paste the service_role/secret key into website files.
5. In Supabase Dashboard go to Authentication > Users and create the OWNER email/password account.
6. Upload the complete cameo_premium folder to your hosting.
7. Open /admin.html and sign in with the owner account.
8. Add products from admin.html. Products saved in Supabase will be visible to all website visitors.

PRODUCT IMAGE STORAGE
---------------------
The SQL creates a public bucket named product-images. Only authenticated users can upload/update/delete images. Everyone can view product images.

INITIAL PRODUCTS
----------------
The existing 72 products remain built into the website as a fallback so the site is not empty before database setup. Once the Supabase products table contains records, the storefront uses database products.

SECURITY NOTE
-------------
The included RLS allows any authenticated Supabase user in this project to manage products. For this shop, create only the owner admin account. If you later add customer accounts, tighten the RLS to an explicit admin allow-list/profile role before enabling those accounts.
